# 芯弦 (XinXian) - 高云 Tang FPGA 实时多音色合成电子乐器

本作品在 **高云 Tang 系列 FPGA** 上以纯 HDL 逻辑实现了一台实时多音色合成电子乐器。

系统不含任何预录 PCM 音频，所有声音均由 FPGA 逐样本、逐声部实时合成：并行振荡器阵列产生多个独立声部，经 ADSR 包络调制与多声部混音后，由 I2S 接口送入板载 DAC 功放解码发声，**控制信号到音频输出总延迟小于 10ms**。

演奏端自主设计双维度交互，分别负责音高选择与力度表情。

---

## 🛠️ 硬件架构

*   **主控核心**：Sipeed Tang Nano 20K (高云 GW2AR-LV18QN88C8/I7)
*   **音频 DAC**：PCM5102 (I2S 接口)
*   **功放模块**：PAM8403 (D类音频功放)
*   **交互输入**：4x4 矩阵键盘
*   **发声单元**：无源小喇叭
